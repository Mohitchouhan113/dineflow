DineFlow — Multi-Vendor Restaurant Management PlatformDineFlow is a comprehensive, multi-tenant SaaS platform built for restaurants, cafes, and eateries. It provides an end-to-end digital workflow—from customer QR ordering and real-time kitchen tracking to vendor subscription billing and multi-tenant analytics.Key FeaturesMulti-Tenant Data Isolation: Robust backend architecture ensuring zero data leakage across vendors.Customer Public Menu & QR Ordering: Instant mobile-friendly ordering interface with live order status updates.Real-Time Kitchen Display System (KDS): Powered by Socket.IO for instantaneous communication between customers, front-of-house, and kitchen staff.Tiered SaaS Subscription Engine: Enforces dynamic plan limits (BASIC vs. PRO) at both the UI and secure API layers (menu items, categories, chefs, tables, analytics range).Payment Integration: Embedded Razorpay support for both restaurant customer orders and automated vendor subscription lifecycle management.Vendor Operations Dashboard: Comprehensive management for menus, table management, chef allocation, restaurant schedules, and business analytics.Super Admin Panel: Centralized oversight for vendor accounts, subscription syncing, and payment tracking.Tech StackLayerTechnologiesFrontendReact, Vite, Socket.IO Client, Tailwind CSS / UI LibrariesBackendNode.js, Express.js, Socket.IODatabaseMongoDB (Mongoose)PaymentsRazorpay IntegrationAuthenticationJWT, Bcrypt
